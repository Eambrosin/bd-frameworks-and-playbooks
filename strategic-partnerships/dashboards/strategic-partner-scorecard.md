# Strategic Partner Scorecard

## Objective

Evaluate potential strategic partners using a weighted scoring methodology to support international market expansion decisions.

---

## Scoring Framework

| Criteria              | Weight | Score (1-5) | Weighted Score |
| --------------------- | ------ | ----------- | -------------- |
| Market Coverage       | 20%    |             |                |
| Industry Reputation   | 15%    |             |                |
| Financial Stability   | 15%    |             |                |
| Strategic Alignment   | 20%    |             |                |
| Commercial Capability | 10%    |             |                |
| Existing Client Base  | 10%    |             |                |
| Regulatory Compliance | 10%    |             |                |

---

## Interpretation

### 90-100

Strategic Priority Partner

### 75-89

Strong Partnership Candidate

### 60-74

Conditional Partnership

### Below 60

Not Recommended

---

## Executive Recommendation

Document key strengths, risks and next-step actions before advancing to partnership negotiations.

---

## Use Cases

* Distributor Selection
* Channel Partnerships
* Joint Ventures
* International Market Entry
* Technology Alliances
* Government Partnerships (B2G)
