# Partner / Distributor Due Diligence Checklist

Use this checklist before committing meaningful commercial resources, exclusivity, inventory, market rights or brand exposure to a new partner.

## 1. Corporate Identity

- [ ] Legal entity name verified
- [ ] Registration / incorporation verified
- [ ] Ownership structure understood
- [ ] Key directors / managers identified
- [ ] Operating history checked
- [ ] Group companies / affiliates understood

## 2. Commercial Fit

- [ ] Target industries overlap with our ICP
- [ ] Customer base is relevant
- [ ] Geographic coverage is documented
- [ ] Sales model is understood
- [ ] Existing product portfolio is compatible
- [ ] Potential channel conflict identified
- [ ] Competing brands / principals mapped
- [ ] Expected commercial contribution is explicit

## 3. Commercial Capability

- [ ] Sales-team size and structure validated
- [ ] Named commercial owner for the partnership
- [ ] Lead-generation process understood
- [ ] CRM / pipeline discipline assessed
- [ ] Customer-reference calls completed where appropriate
- [ ] Historic sales performance discussed
- [ ] Launch resources and budget clarified

## 4. Operational Capability

- [ ] Warehousing / logistics capability assessed if relevant
- [ ] Installation / implementation capability assessed
- [ ] Service and maintenance capability assessed
- [ ] Training capability assessed
- [ ] Customer-support model understood
- [ ] Territory coverage is operationally realistic

## 5. Financial & Legal

- [ ] Basic financial stability reviewed
- [ ] Credit / payment expectations agreed
- [ ] Tax and invoicing structure understood
- [ ] Required licenses / permits verified
- [ ] Sanctions / compliance checks completed where applicable
- [ ] Litigation / reputational red flags reviewed
- [ ] Insurance requirements considered

## 6. Strategic Alignment

- [ ] Why the partner wants the relationship is understood
- [ ] Both sides' contribution is explicit
- [ ] Expected value for each side is credible
- [ ] Decision-makers on both sides are identified
- [ ] Short-term targets align with long-term positioning
- [ ] Exclusivity, if requested, is supported by measurable commitments

## 7. Governance

- [ ] KPIs defined
- [ ] Pipeline-reporting cadence defined
- [ ] Quarterly / monthly review structure agreed
- [ ] Escalation path agreed
- [ ] Marketing responsibilities defined
- [ ] Lead ownership rules defined
- [ ] Customer ownership / account-conflict rules defined

## 8. Pilot Before Scale

Before granting broad rights, test the relationship through the smallest meaningful commercial commitment.

Possible pilot structures:

- non-exclusive 90-day development period
- named-account program
- limited territory
- defined lead-generation target
- first-customer milestone
- joint campaign with explicit KPIs

## Decision Output

Document one of four decisions:

```text
PROCEED
PROCEED WITH CONDITIONS
PILOT / VALIDATE FIRST
DO NOT PROCEED
```

Every decision should include evidence, unresolved risks and the next commercial action.
